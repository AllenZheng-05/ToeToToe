# Toe to Toe design kit

The chosen design for Toe to Toe, exported on 16 November 2026.

- `assets/` holds the seven stage images. The PNG files are cutouts with transparency.
- `mocks/` holds one static HTML file per screen at 1280 by 720. They are layout references, not game code: every position, colour, font and label in them is the intended design. Open them in a browser to see the screens with the real fonts (Bungee, Special Elite and Permanent Marker from Google Fonts).
- `screenshots/` holds a picture of each mock. These were rendered without internet access, so the lettering uses stand-in fonts. Trust the mocks over the screenshots for type.

Screens: 1 title, 2 room lobby, 3 puppet workshop, 4 battle theme, 5 duel (attacking), 6 duel (defending), 7 victory.

The two puppets and their swords in the mocks are example player drawings, built as inline SVG. In the game they are bitmaps drawn by players in the workshop.

The source images are free images chosen by Allen.
