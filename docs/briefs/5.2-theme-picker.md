## API

```ts
// src/theme/theme.ts
export interface LoadedTheme {
  info: TrackInfo;                 // source, id, title, bpm (as set by the player), firstBeatOffset, hash/bytes for uploads
  buffer: AudioBuffer;             // decoded (or synthesised for the click track)
  /** Loop region in buffer seconds: whole phrases after the first beat. For the click track, its exact loop. */
  loopStart: number;
  loopEnd: number;
  /** The encoded file for sending to the other player; null for house tracks and the click track. */
  file: { data: ArrayBuffer; mime: string } | null;
}
export interface ThemeDeps { store: Store; engine: AudioEngine; tunables: Tunables; house?: TrackSource }
/** Resolve a TrackInfo to something playable. Rejects with a SongRejection-style reason on failure. */
export function loadTheme(info: TrackInfo, deps: ThemeDeps): Promise<LoadedTheme>;
/** The theme named by the `selectedThemeId` setting, falling back to the click track if it is missing or fails to load. Never rejects. */
export function loadSelectedTheme(deps: ThemeDeps): Promise<LoadedTheme>;
/** Decode and load a song received from the other player (untrusted bytes): checkSongBytes, decode, checkSongDuration, sha256 must equal offer.hash. Rejects with a plain message otherwise. */
export function loadOfferedSong(offer: ThemeOffer, data: ArrayBuffer, deps: ThemeDeps): Promise<LoadedTheme>;
/** Start a LoadedTheme so that its first beat is heard at clock time `startTime`, looping over the loop region. */
export function playTheme(theme: LoadedTheme, engine: AudioEngine, startTime: number): PlayHandle;

// src/theme/picker.ts
export interface ThemePickerOptions extends ThemeDeps {
  onDone?(selected: LoadedTheme): void;
}
export function createThemePicker(opts: ThemePickerOptions): { root: HTMLElement; destroy(): void };

// src/theme/metronome.ts
/** Schedules `tick` sound effects on the beat ahead of time on the audio clock (a look-ahead scheduler: a 25 ms interval that schedules every beat falling in the next 120 ms; the interval only wakes the scheduler, the audio clock times the ticks). Pure planning function exported for tests. */
export function beatsToSchedule(fromTime: number, toTime: number, grid: { bpm: number; startTime: number }, alreadyScheduledThrough: number): number[];
export function startMetronome(engine: AudioEngine, grid: { bpm: number; startTime: number }): { stop(): void };
```

## Picker behaviour (laid out as in mock 4, 1280x720 design-space root)

- **List** of themes: the click track, the house tracks from `createHouseTrackSource()` (titles as in the manifest, which says "Placeholder"), then the player's uploaded songs from `createLocalTrackSource(store)`. Each row: title, tempo, credit, a "Listen" toggle, and for uploads "Remove" (two-click confirm). Selecting a row stores `selectedThemeId`. If the house manifest cannot be fetched, show the click track and uploads only, with no error screen.
- **Upload:** an "Upload a song" button (file input accepting the four types) and drag-and-drop onto the panel. Flow: read the file, `checkSongBytes`, decode with `engine.decode`, `checkSongDuration`, `sha256Hex`, `detectBeat`, store a `StoredSong`, select it. Any failure shows `songRejectionMessage(...)` on a typed note; nothing is stored. Show progress states "Reading…", "Finding the beat…". If the same hash is already stored, select the existing one.
- **Privacy note**, always visible near the upload button: "Your song stays on this device. It is sent only to the friend in your room." Also the limits: "MP3, OGG, WAV or M4A, up to 10 MB and six minutes."
- **Setting the beat** for the selected upload (and read-only for house tracks): the tempo and first-beat offset shown as numbers; nudge buttons for tempo (−1, −0.1, +0.1, +1), "Half" and "Double" (`halveOrDouble`), nudge buttons for the first beat (−20 ms, −5 ms, +5 ms, +20 ms); "Listen with click" plays the song from its start with the metronome over it using the current setting, restarting when a nudge changes it; **tap-along**: a big "Tap along" button that the player taps on the beat while the song plays; after 4 taps show the tempo from `tempoFromTaps` and the offset from `offsetFromTaps` with a "Use these" button, and show `tapError` against the current setting ("Your taps are 12 ms late"). Tap times are taken from `engine.clock.timeOfEvent(event.timeStamp)` relative to when the song started. Changes are saved to the stored song at once.
- **Done** button calls `onDone` with the loaded selected theme. Stop all preview audio on Done and on `destroy`.
- `data-testid`s: `theme-row-<id>`, `listen-<id>`, `upload`, `upload-input`, `bpm`, `offset`, `bpm-minus-1`, `bpm-minus-01`, `bpm-plus-01`, `bpm-plus-1`, `half`, `double`, `offset-minus-20`, `offset-minus-5`, `offset-plus-5`, `offset-plus-20`, `listen-click`, `tap`, `use-taps`, `theme-message`, `done`.
