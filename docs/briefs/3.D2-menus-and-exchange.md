## Exchange of drawings and songs (new module `src/scenes/exchange.ts`, with pure parts unit tested)

Runs over the room's `Transport` alongside `Room` (which ignores these). Everything received is untrusted.

- **Drawings.** When the transport is open and after `hello`, each side sends its selected puppet: three blobs with `BlobMeta` kinds `puppet-head`, `puppet-sock`, `puppet-sword` (`mime: 'image/png'`, `bytes`, `name` = the puppet's name on the head blob). Sent again whenever the player changes puppet in the lobby. The receiver accepts each only if `checkDrawingBytes(data, kind)` passes, then decodes it with the browser (`decodeDrawing` / `createImageBitmap`); a failed check or decode is ignored and that part falls back to a preset part. When all three have arrived the friend's puppet is shown in the lobby and passed to the duel through `MatchSetup.puppets`.
- **Theme.** The host's current theme is offered with `room.setTheme(toThemeOffer(info))` whenever it changes and when the guest joins. For a house track or the click track the guest loads it itself with `loadTheme`. For an upload the host then sends the file as a blob (`kind: 'song'`, `mime`, `bytes`, `hash`); the guest loads it with `loadOfferedSong(offer, data, deps)` (type sniffing, size and length limits, SHA-256 must match the offer) and answers `{ t: 'themeReady', hash, ok }`. If it fails the guest shows the plain reason and the host is told ("Your friend could not load that song") and can pick another theme. The guest does not store the host's song in its own saved songs.
- **Gating.** The guest cannot become Ready until the offered theme is loaded on its side; the host's "Start" also requires `themeReady ok` for the current theme. If the host changes theme, the guest's Ready resets.
- **In the match** both sides call `playTheme(theme, engine, grid.startTime)` with their own loaded copy, and the room's `start` uses the theme's tempo (it already reads the offered theme's `bpm`). The bot match uses `loadSelectedTheme` and the selected puppet too.
- Under the upload control on the theme scene the privacy sentence from the picker must be visible; do not add any other data collection.
