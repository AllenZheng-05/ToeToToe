# Brief 3.B: UI kit (DOM and CSS)

**Goal.** The design's interface vocabulary as reusable DOM/CSS components, with self-hosted fonts, checked against the mocks on a dev page: ransom-note letter tiles, label strips, tape and torn-paper notes, buttons, inputs, bars, phrase dots, banners. Later tasks build the title, lobby, workshop, theme, duel HUD and victory screens from these; you do not touch the scenes.

**Read first:** `CLAUDE.md` (product rules: plain labels), `docs/DESIGN.md`, `docs/DESIGN_SPEC.md` (sections 3, 5, 6, 7 are your source of exact CSS), and the mocks in `design/mocks/` for anything the spec leaves unclear. Look at `design/screenshots/` (rendered with stand-in fonts; trust the mocks for type).

**Files you own (create):** `src/ui/kit/**`, `dev/uikit.html`, `dev/uikit.ts`, `tests/unit/kit.test.ts`. Touch nothing else. Other agents are editing `src/ui/*.ts` (top level), `src/style.css`, `src/app`, `src/scenes`, `src/stage`, `tests/e2e`. Add no dependencies: `@fontsource/bungee`, `@fontsource/special-elite` and `@fontsource/permanent-marker` (5.3.0) are installed.

## What to build

- `src/ui/kit/fonts.ts`: imports the three `@fontsource` CSS files (latin subsets only if the packages offer them) so Vite bundles the font files; exports `fontsReady(): Promise<void>` that resolves when all three are loaded (`document.fonts.load`), never rejecting. No font CDN at runtime.
- `src/ui/kit/kit.css`: CSS custom properties for every design colour (`--mat: #2F6B52`, `--ink: #1B1210`, `--paper: #FFFDF5`, `--yellow: #FFE14D`, `--red: #D42A40`, `--blue: #2456C8`, `--pink: #F48FB1`, `--parried: #7BC67B`, `--tape: rgba(244,228,170,0.9)`), and one class per component, all prefixed `tt-`. Sizes are in px for the 1280x720 design space (the app scales the whole overlay). Follow the mocks' exact CSS; where a mock clips a `box-shadow` with `clip-path`, use a `filter: drop-shadow` on a wrapper or a pseudo-element so the hard shadow is visible. Static DOM may use CSS shadows and outlines freely (rule 8 in CLAUDE.md is about the Pixi stage).
- `src/ui/kit/kit.ts`: small functions returning `HTMLElement`s. No framework.

```ts
export interface TileOptions { size?: number; seed?: number; palette?: 'title' | 'banner' | 'win' }
/** Ransom-note lettering: one tile per character, each with its own colours, font, slight rotation and offset as in the mocks, chosen deterministically from `seed` and the character index (a seeded generator, so a given text always looks the same). Spaces become gaps. Has aria-label with the plain text; tiles are aria-hidden. */
export function letterTiles(text: string, o?: TileOptions): HTMLElement;
/** Pure: the per-tile style choices, exported for testing. */
export function tileStyles(text: string, seed: number, palette: 'title' | 'banner' | 'win'): Array<{ char: string; rotate: number; bg: string; fg: string; font: string; dy: number }>;
export function labelStrip(text: string, o?: { tone?: 'ink' | 'red' | 'blue'; rotate?: number }): HTMLElement;      // black strip, white type
export function tapeNote(text: string, o?: { rotate?: number }): HTMLElement;                                        // marker on masking tape
export function tornNote(text: string, o?: { rotate?: number; width?: number }): HTMLElement;                        // typed note on torn paper
export function button(label: string, o?: { variant?: 'primary' | 'secondary' | 'small' | 'danger'; testId?: string; disabled?: boolean; onClick?: () => void }): HTMLButtonElement;
export function textInput(o: { label: string; value?: string; placeholder?: string; maxLength?: number; testId?: string; onInput?: (v: string) => void }): { root: HTMLElement; input: HTMLInputElement };
export interface BarHandle { root: HTMLElement; set(value: number, max: number): void }
/** A labelled bar: `kind` 'health' is red and labelled "Health", 'stamina' is blue and labelled "Stamina" (exactly those words; if the mocks use capitals, do it with CSS text-transform so the text content stays "Health"/"Stamina"). Sets data-value and an aria progressbar role. `align` mirrors it for the right-hand player. */
export function bar(kind: 'health' | 'stamina', o?: { align?: 'left' | 'right'; testId?: string }): BarHandle;
export interface PlayerPlateHandle { root: HTMLElement; setName(n: string): void; health: BarHandle; stamina: BarHandle; setWinded(w: boolean): void }
/** Name plus the two bars as they sit on the ledge in the duel mocks. */
export function playerPlate(o: { align: 'left' | 'right'; testIdSuffix: string }): PlayerPlateHandle;
export interface DotsHandle { root: HTMLElement; set(state: { slots: number; current: number; filled: boolean[]; tone: 'attack' | 'defend' | 'idle' }): void }
/** The eight half-beat phrase dots in the middle of the ledge. */
export function phraseDots(): DotsHandle;
export function actCounter(): { root: HTMLElement; set(act: number, of: number, wins: [number, number]): void };  // "Act 2 of 3"
/** Big banner in letter tiles ("ATTACK!", "PARRY!", "NAME WINS!", a count-in number). `set` re-renders only when the text changes. */
export function banner(): { root: HTMLElement; set(text: string | null, palette?: 'banner' | 'win'): void };
/** A grade pop-up ("Bravo!", "Good", "Miss") that animates and removes itself (CSS animation; `animationend`). */
export function gradePop(grade: 'bravo' | 'good' | 'miss'): HTMLElement;
export function progressBar(o?: { label?: string }): { root: HTMLElement; set(fraction: number, label?: string): void }; // for sending drawings and songs
export function panel(o?: { title?: string; rotate?: number }): HTMLElement;                                           // a paper panel for menus and dialogs
```

All interactive elements: visible focus style, at least 44 px tap height, no hover-only affordances, `:disabled` styling. Text never relies on colour alone.
