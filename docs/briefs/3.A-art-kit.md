## Components

```ts
// src/stage/art/cutout.ts
export interface CutoutOptions {
  outline?: number;        // white scissor edge, px. Default 3
  shadowX?: number;        // default 5
  shadowY?: number;        // default 6
  shadowAlpha?: number;    // default 0.28
  scale?: number;          // resample the source by this factor before baking. Default 1
}
/** Pure geometry: how much the baked canvas grows on each side, so sprites can be positioned by the original image's box. */
export function cutoutPadding(o?: CutoutOptions): { left: number; top: number; right: number; bottom: number };
/** Bakes the cutout treatment once on an offscreen canvas: hard shadow (no blur), solid white outline following the alpha edge, then the image. For opaque rectangles (JPEG) the outline is a white border. */
export function bakeCutout(source: CanvasImageSource, width: number, height: number, o?: CutoutOptions): HTMLCanvasElement;
/** Convenience: bake and wrap in a Pixi Texture. */
export function cutoutTexture(source: CanvasImageSource, width: number, height: number, o?: CutoutOptions): Texture;
```
Bake the outline with canvas compositing (draw the silhouette offset around a circle of the outline radius, or use a dilated alpha mask), not with a filter at render time.

```ts
// src/stage/art/puppetView.ts
export interface PuppetImages { head: CanvasImageSource; sock: CanvasImageSource; sword: CanvasImageSource } // at PARTS sizes
/** Rasterise a preset's three SVGs to canvases at PARTS sizes (browser). */
export function loadPresetImages(preset: PuppetPreset): Promise<PuppetImages>;
/** A puppet drawn from baked cutout textures of its three parts. `setPose` applies a RigPose from solveRig: segment sprites are pooled and added or removed as the count changes; brass pins (gold `#D4AF37` with `#7A5C12` edge, radius 7) are drawn at the joints. */
export class PuppetView {
  constructor(images: PuppetImages, facing: 1 | -1);
  readonly container: Container;
  setImages(images: PuppetImages): void;   // re-bake when a drawing changes
  setPose(pose: RigPose): void;
  destroy(): void;
}
```

```ts
// src/stage/art/marks.ts
/** Pre-rendered textures for every target and strike state (DESIGN_SPEC section 3), numbers 1 to 8, baked once. */
export function createMarkTextures(): MarkTextures;
/** Draws the attack-phase strikes (red numbered discs joined by a red line, newest yellow) and the defend-phase targets (yellow disc, ink double ring and number; a solid ink ring that closes in and meets the disc edge at timeToHit = 0; green with a tick once parried; a clear missed state). Takes positions in play-area fractions and converts with `playToDesign`. Target radius on screen matches `tunables.targetRadius` (fraction of play width), so what is drawn is what is judged. */
export class MarksView {
  constructor(textures: MarkTextures);
  readonly container: Container;
  /** ringLeadBeats: how many beats before its time a target's ring starts closing (default 2). */
  update(view: DuelView, tunables: Tunables, bpm: number, opts?: { touch?: boolean; ringLeadBeats?: number }): void;
  destroy(): void;
}
```

The closing ring may be drawn with a Pixi `Graphics` circle or a scaled ring sprite each frame (that is geometry, not a filter). Sprites are pooled; no per-frame texture creation.
