## Pure core (unit tested in Node, no DOM)

```ts
// src/workshop/bitmap.ts — operates on { width, height, data: Uint8ClampedArray } (RGBA, like ImageData)
export interface Bitmap { width: number; height: number; data: Uint8ClampedArray }
export function createBitmap(width: number, height: number): Bitmap;            // transparent
export function cloneBitmap(b: Bitmap): Bitmap;
export type Rgba = [number, number, number, number];
/** Stamp a filled, hard-edged circle (no anti-aliasing, so fill works cleanly). */
export function stampCircle(b: Bitmap, cx: number, cy: number, radius: number, color: Rgba): void;
/** A brush stroke segment: circles stamped along the line so there are no gaps. color [0,0,0,0] erases. */
export function strokeLine(b: Bitmap, x0: number, y0: number, x1: number, y1: number, radius: number, color: Rgba): void;
/** Scanline flood fill from (x, y) over the contiguous region of the exact same RGBA as the start pixel. No-op if out of bounds or already that colour. */
export function floodFill(b: Bitmap, x: number, y: number, color: Rgba): void;
export function isBlank(b: Bitmap): boolean;
// src/workshop/history.ts
/** Undo/redo of whole-bitmap snapshots, capped (default 30 steps). */
export class History { constructor(limit?: number); push(b: Bitmap): void; undo(current: Bitmap): Bitmap | null; redo(current: Bitmap): Bitmap | null; readonly canUndo: boolean; readonly canRedo: boolean; clear(): void }
// src/workshop/palette.ts
export const PALETTE: string[];        // exactly twelve colours: the design colours plus what the mock's palette shows
export const BRUSH_SIZES: [number, number, number]; // radii in drawing pixels, e.g. 4, 9, 18
```

```ts
/** PNG blobs (at PARTS sizes) for a preset, rasterised from its SVG in the browser. */
```

Workshop behaviour, laid out as in mock 3 inside a 1280x720 design-space root:

- **Three drawing surfaces** (head 320x240, sock piece 160x120, sword 320x80), switched with three labelled tabs "Head", "Sock piece", "Sword"; the active one is shown enlarged (integer or fractional CSS scale, `image-rendering: pixelated` off, crisp enough) on a paper sheet with a transparent-checker or paper background.
- **Guides** on each surface, drawn as an overlay that is not part of the drawing: the dashed guide box (the safe area), and the fixed anchor points from `PARTS` with short plain labels ("joins the sock", "sword goes here", "pin", "handle", "tip"). A "Guides" toggle hides them.
- **Tools:** Brush, Eraser, Fill, Undo, Redo, Clear (with a confirm step that is a second click on the same button, not a browser dialog), three brush sizes, twelve colours. Pointer Events only; drawing works with mouse, pen and touch; strokes are captured with pointer capture and continue outside the canvas edge. Undo history is per surface.
- **Live preview on the stage:** a small 2D-canvas preview of the assembled puppet posed with `solveRig` (base at the bottom, the sword tip slowly sweeping, or following the pointer while it is over the preview), using `PART_SCALE` and the placements, redrawn when a stroke ends. Brass pins drawn at the joints.
- **Name field** (max 32 characters, default "My puppet").
- **Saved puppets row:** the four presets first (labelled by their names), then the player's saved puppets as thumbnails. Clicking one selects it and loads it into the editor. Editing a preset and saving creates a new saved puppet (presets are never overwritten). Buttons: "Save" (writes a `StoredPuppet` with PNG blobs via `canvas.toBlob`, updates the row, stores `selectedPuppetId`), "New" (blank surfaces), "Delete" (saved puppets only, same two-click confirm), "Done".
- Drawings are saved in the store at once on Save; the selection (`selectedPuppetId` setting, a saved id or a preset id) is stored whenever it changes. If the store is not persistent (`store.persistent === false`), show a typed note: "This browser can't save drawings. They will last until you close the tab."
- A blank part is allowed but Save shows a note "Your head is blank" (or sock piece, or sword) and still saves.
- All buttons have `data-testid`s (`tool-brush`, `tool-eraser`, `tool-fill`, `undo`, `redo`, `clear`, `size-0..2`, `colour-0..11`, `tab-head`, `tab-sock`, `tab-sword`, `puppet-name`, `save`, `new`, `delete`, `done`, `saved-<id>`, `canvas`).

Palette has twelve distinct valid colours.
