## Fonts

Self-hosted through `@fontsource` 5.3.0 (the latin 400 files, imported in `src/ui/kit/fonts.ts`). The licence is read from each package's `package.json` and `LICENSE` in `node_modules`.

| Font | Package | Licence found | Copyright line in the LICENSE file |
|---|---|---|---|
| Bungee | `@fontsource/bungee` | OFL-1.1 (SIL Open Font License 1.1) | Copyright 2023 The Bungee Project Authors (https://github.com/djrrb/Bungee) |
| Special Elite | `@fontsource/special-elite` | Apache-2.0 | Copyright (c) 2010 by Brian J. Bonislawsky DBA Astigmatic (AOETI) |
| Permanent Marker | `@fontsource/permanent-marker` | Apache-2.0 | Copyright (c) 2010 by Font Diner, Inc. |

Both licences allow use and bundling in a web game. OFL requires that the font is not sold on its own and that the licence travels with it; Apache-2.0 requires keeping the licence and notices when redistributing. The fonts are served as files from our own origin (not Google Fonts), so a credits or licences page that links these three licences is the safe way to comply. Fonts are not committed to the repo; they arrive through pnpm.

## Tracks (`public/tracks/`)

| File | Notes |
|---|---|
| `placeholder-march-100.wav` | 100 BPM |
| `placeholder-waltz-off-126.wav` | 126 BPM |
| `placeholder-gallop-152.wav` | 152 BPM |
| `tracks.json` | Manifest |

Generated by `scripts/generate-tracks.ts` (`pnpm tracks`). They are synthesised in code, so there are no third-party rights; the manifest says so. They are placeholders: replace them with the tracks Allen chooses.

To add a track:

1. Put the audio file in `public/tracks/` (the file name is used in the URL; avoid spaces).
2. Add an entry to `public/tracks/tracks.json` with `id` (unique), `title`, `file`, `bpm`, `firstBeatOffset` (seconds from the start of the file to the first beat), `credit` and `licence`. Fill `credit` and `licence` truthfully; do not leave the placeholder text on a real track.
3. Remove the placeholder entries and files when no longer wanted, then run `pnpm build` and check the track in the battle theme picker.
4. Tracks that are not yours need a licence that allows public distribution from the site. Files in `public/tracks/` are downloadable by anyone.

## Sounds

The click track and sound effects (`src/audio/click.ts`, `src/audio/sfx.ts`) are synthesised with Web Audio in code. No sample files, no third-party rights.

## Preset puppets

Drawn as SVG in `src/puppet/presets.ts`, derived from the design mocks in `design/mocks/` (which were built as inline SVG). Original work for this project; the mocks themselves are Allen's chosen design, with no third-party art recorded.

## Player-made content

Drawings and songs are made or uploaded by players and kept on their device (drawings optionally in Supabase). Songs are never uploaded to a server and are sent only to the friend in the room.
